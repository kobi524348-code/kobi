# 🦒 Giraffe Cafe

自家焙煎コーヒーと手づくりスイーツを楽しめる、街のちいさな隠れ家カフェ「Giraffe Cafe」のホームページです。追加のビルドツールや依存パッケージは不要で、そのままブラウザで開くだけで動作します。

## ✨ 特徴

- **レスポンシブデザイン** — スマホ・タブレット・PC に対応（モバイルはハンバーガーメニュー）
- **日本語 / 英語の2言語** — ヘッダーの `JP / EN` でワンクリック切り替え（`hreflang` 対応）
- **ダークモード** — OS設定に自動追従＋ヘッダーのトグルで手動切り替え（選択は保存されます）
- **営業中/営業時間外のリアルタイム表示** — 現在の曜日・時刻から自動判定
- **予約フォーム** — 入力バリデーション付き（※現在はデモ動作。送信は行いません）
- **スクロールアニメーション**（`prefers-reduced-motion` に配慮）
- **SEO対応** — OGP / Twitterカード / 構造化データ（JSON-LD, LocalBusiness）
- **アクセシビリティ** — スキップリンク、ランドマーク、`aria` 属性
- カスタムSVGきりんイラスト・ファビコン・PWAマニフェスト

## 📁 ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 日本語トップページ |
| `en.html` | 英語ページ |
| `styles.css` | 共有スタイルシート（ライト/ダーク両テーマ） |
| `404.html` | エラーページ（GitHub Pages が自動使用） |
| `site.webmanifest` | PWA用マニフェスト |

> スタイルは `styles.css` に一本化されているため、見た目の変更は基本このファイル1つを編集すれば両ページに反映されます。

## 🚀 ローカルで確認する

`index.html` をブラウザにドラッグ＆ドロップするだけでも表示できます。フォントやマニフェストまで含めて確認したい場合は、簡易サーバーの利用がおすすめです。

```bash
# Python がある場合
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## ✏️ 内容の差し替え

現在、以下の情報は**仮の値（ダミー）**です。実際の店舗情報に置き換えてください。`index.html` と `en.html` の両方を更新します。

- **住所・郵便番号** … `<section id="info">` 内、および各ページ `<head>` の JSON-LD
- **電話番号** … 予約セクションとアクセスセクション、JSON-LD の `telephone`
- **営業時間・定休日** … アクセスセクションの表示、JSON-LD の `openingHoursSpecification`、および `styles.css`…ではなく各ページ末尾の `<script>` 内 `hours`（曜日ごとの営業時間・定休日判定）
- **SNSリンク** … フッターの Instagram / X / Facebook（現在は `href="#"`）
- **メニューと価格** … `<section id="menu">`
- **ギャラリー画像** … 現在は絵文字プレースホルダー。`<figure>` を `<img>` に差し替え

### 営業時間ロジックの例

各ページの `<script>` 内にある `hours` を編集します（`0` = 日曜、`3`（水曜）は `null` で定休日）。

```js
const hours = { 0: [9, 21], 1: [8, 20], 2: [8, 20], 3: null, 4: [8, 20], 5: [8, 20], 6: [9, 21] };
```

## 🌐 GitHub Pages で公開する

1. GitHub にリポジトリをプッシュ
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch` にし、ブランチ（例：`main`）と `/ (root)` を選択して保存
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`404.html` は存在しないURLへのアクセス時に自動的に使用されます。

## 📝 予約フォームを実際に送信するには

現在の予約フォームは動作デモで、データ送信は行いません。実運用では以下のようなフォーム送信サービスの利用が手軽です。

- [Formspree](https://formspree.io/) / [Getform](https://getform.io/) など（`<form>` の `action` にエンドポイントを設定）
